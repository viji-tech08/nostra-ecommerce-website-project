
# Nostra Ecommerce Website

## About the Project
Nostra is a responsive ecommerce website built using HTML, CSS, and JavaScript. Users can explore new arrivals, browse most-wanted products, view collections, and contact the website.

## Features
- Home Page
- New Arrivals Page
- Most Wanted Products
- Collections Page
- Contact Us Page
- Responsive Website Design
- Interactive Navigation
- JavaScript Functionality

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Pages
1. Home
2. New Arrivals
3. Most Wanted
4. Collections
5. Contact Us

- Styling responsive web pages
- Using JavaScript for DOM manipulation
- Adding interactive website functionality
