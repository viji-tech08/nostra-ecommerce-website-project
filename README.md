# Nostra — Ecommerce Student Project

A responsive fashion ecommerce **frontend demo** built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home page with hero, new arrivals, most wanted and newsletter demo.
- `new-arrivals.html` — New product listing and price sorting.
- `most-wanted.html` — Popular product listing and price sorting.
- `collections.html` — Product search, category filtering and price sorting.
- `contactus.html` — Contact form with client-side validation.

## Technologies
- HTML5
- CSS3 (responsive layouts)
- Vanilla JavaScript (DOM, events, array filtering and form validation)

## Run locally
1. Download or clone this repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
